# ViralOS v33: one-click local neural narration + MP4

Saved live AppDeploy snapshot: `1792934613249`, 2026-10-25.

User's uploaded synthetic test MP4 was independently ffprobed: 1080x1920 H.264, 48kHz AAC, duration 21.077333 s. The beep was intentionally generated by the separate self-test, not a real voice. This test is now moved under a collapsed technical panel.

New source module `src/local-ai-voice.ts` lazily loads `kokoro-js` 1.2.1 (`q8` WASM from `onnx-community/Kokoro-82M-v1.0-ONNX`, open weights) on owner action, synthesizes saved English text in small chunks to PCM WAV, bounds narration to 15–45 s, and provides audio to browser MP4 renderer. New Videostudio button selects one of three English voices and produces the H.264 9:16 video with voice/audio in the same click.

Runtime safety: never send manuscript to an external cloud voice API, verify saved project version and owner before and after synthesis, discard late results if edited/switching accounts, no automatic YouTube upload or public release. Generated audio/visuals still require human content, timing, source and rights review.

AppDeploy build and smoke QA reported no frontend/network errors. Real-world Kokoro model download and complete voice/video output have NOT been user-verified; browser internet, memory and WASM limitations can block execution. No claim of fully autonomous end-to-end trending-to-YouTube pipeline yet.
